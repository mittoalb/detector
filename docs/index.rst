detectors
=========

Camera-agnostic EPICS areaDetector IOC and Qt GUI for scientific cameras.
Currently supports Hamamatsu ORCA Fire, Teledyne FLIR Oryx, and Teledyne
Photometrics Kinetix. Adding a new camera is a single-file addition.
